# 3.1.1 迁移失败复查（2026-10-29）

实机 3.1.0 首次登录激活失败，错误为 `Gjs_effect_clip_shadow_effect_ is already registered`。
自动恢复已执行，旧扩展重新启用。根因是旧 MacStyle 的 GObject 类型在停用后仍留在
Shell 进程里；整合版匿名 shader 类生成了相同类型名。原测试只有新扩展独立启动，
没有覆盖旧扩展已经导入、随后切换的场景。

| 发现 | 修复与验证 |
| --- | --- |
| 匿名效果类型与旧 MacStyle 冲突；其他复用类也缺少明确隔离 | 全部 21 个注册类使用独立 LinuxBeautify 类型名；复制实际旧插件到临时环境，先全部 ACTIVE，再切换中英文整合版 |
| 失败或停用扩展的 ES 模块仍被当前 Shell 缓存 | 安装前识别已加载状态；记录 boot/PID/start-time，新的 Shell 会话才允许激活 |
| 导入过程中短暂 ERROR、错误列表为空 | 等待异步导入完成；仅有实际错误记录时立即判失败，超时仍报错 |
| 登录脚本只检查 ACTIVE，错误日志缺少模块原因 | 等待旧模块加载完成；两次检查唯一 Dock、放大器、语言版和输入模块；记录 GetExtensionErrors 和 Shell 日志再恢复 |
| 首次本机安装依赖临时修改过的输入保留逻辑 | 正式加入 --preserve-input，保留已有配置/词库/启动项/环境文件；安装与卸载均核验内容未改变 |
| 英文迁移测试会调用宿主 AccountsService | 临时测试包禁用账户语言预设；语言事务仍由模拟 AccountsService 的单元测试覆盖 |

自动激活代码保存在用户状态目录，不依赖备份磁盘挂载；过期安装的登录任务自动取消，
同一 Shell 中提前执行只保留待激活任务，不停用旧插件；同一任务以文件锁防止并发。
重试前另存可恢复快照，保留首次备份。实机修复版需要用户正常注销重登，不能用当前
进程的旧版 ERROR 状态判断磁盘上 3.1.1 的运行结果。

# 3.1.0 共享资源与代码审计

复查范围：项目自有 core、desktop、input 与整合入口的监听、扫描、绘制和启停路径。
保留固定版本 Dock 库的上游结构，没有为了减少行数重写完整上游 Dock。
旧 2.x/3.0.0 发布包已移出 dist，源码和旧包另行备份，新交付目录只生成两版 3.1.0。

| 发现 | 处理 | 验证 |
| --- | --- | --- |
| 同函数的重复订阅使用 Set，取消一处会误删另一处 | 独立订阅 token | 独立取消订阅回归 |
| 一个共享回调异常会中断其他功能 | 分别捕获和报告异常 | 故障回调和后续回调回归 |
| 定时任务内部取消/抛错可能残留跟踪状态 | 统一回调与 scope 生命周期，清理失败继续其余清理 | 自我释放、抛错、清理失败回归 |
| 桌面输入增强与候选面板分别读取焦点 | SharedState 合并 focus/overview/mapped 事件，共享最多 12 层的焦点祖先查找 | 40 次同步刷新请求只读取一次；英文版无焦点监听 |
| 相同候选内容仍重建按钮 | 只在状态改变时增加 revision，位置与内容更新分离 | 20 次相同候选更新不重建，位置移动不重建，选中项仍更新 |
| 同一 Dock 事件/动画内重复枚举、排序图标 | 仅在一次同步调用内缓存列表，结构变化失效，帧结束清空 | 实际 Shell 中一批 20 次查询只枚举一次，放大目标正常 |
| 命中区域没变仍更新输入区域 | 比较可见性、交互状态与几何 | Dock 工作负载及启停验证 |
| 重复 GPU uniform 写入，位置缓存跨实例共享 | 每个 effect 独立缓存，相同值跳过，pipeline 重建时失效 | 真实 GTK 窗口圆角和最大化/最小化还原 |
| 部分外观初始化失败只记日志、丢失句柄 | 交由入口统一回滚，逐项执行禁用清理 | 代码审计和三次正常启停 |
| 空磁盘预处理、失效 Dock 发现入口、旧扫描追踪字段 | 删除无作用结构 | JS 解析和运行验证 |
| 英文版也把已有输入面板视为冲突 | 英文版保留原输入面板，中文版才接管 | 安装器回归及 English headless 激活 |

这些结果证明特定重复工作被消除，不代表整机 CPU/GPU 或内存固定降幅。列表缓存不跨帧，
窗口几何仍按实际动画读取。焦点改变会清空旧候选与位置，密码/PIN 输入不接管候选服务。

中文与英文共用桌面实现及 UUID。中文包独有 input、Fcitx5/Rime 原生运行组件、分发词库
和输入皮肤；英文不包含这些载荷，也不注册焦点协调器。

测试均在临时 HOME、私有 D-Bus/keyfile 和 headless Wayland 中进行，未部署到当前桌面。
真实高刷/HDR 视觉手感、拖动排序、跨显示器与全部应用兼容仍需实机观察。电源和 HDR
默认关闭；测试未执行真实电源操作、热点联网或 HDR 标志切换。

复现方法和结果见 [VALIDATION.md](VALIDATION.md)。
